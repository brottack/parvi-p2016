# Finnish FA Taso Widget Example

This repository demonstrates how match data can be retrieved from the Finnish Football Association's Taso service by using a team's public widget key.

The example page displays the 2026 results of Parolan Visa's P2016 teams at two competition levels. It uses the official Taso/TorneoPal widgets as the data source and processes the widget-generated HTML in the browser.

## What the example does

- Loads a team's completed matches from Taso.
- Loads spring and autumn competition schedules.
- Extracts team names and scorelines from the widget tables.
- Calculates matches played, wins, draws, losses and points.
- Creates separate full-season, spring and autumn standings.
- Presents the same data in desktop- and mobile-friendly layouts.

## Loading team results

The `team_results` widget requires the Taso team ID, season and widget key:

```html
<script src="https://spl.torneopal.fi/torneopal/ajax/[torneopal:team_results:teamid=35139452%26amp;season=2026%26amp;key=XCE7YVFYV7]"></script>
```

Another team or competition level can be loaded by replacing `teamid` and `key` with the values supplied by Taso.

## Loading a competition schedule

The `schedule` widget is used when results for every team in a competition group are needed:

```html
<script src="https://spl.torneopal.fi/torneopal/ajax/[torneopal:schedule:competition=lanjp26%26amp;class=P102%26amp;group=5%26amp;key=XCE7YVFYV7]"></script>
```

The relevant parameters are:

- `competition`: competition identifier
- `class`: competition level or class
- `group`: competition group
- `key`: team widget key

## Calculated standings

The page reads the home team, away team and result cells generated by the widgets. It then calculates the standings in JavaScript using the following point system:

- Win: 3 points
- Draw: 1 point
- Loss: 0 points

These standings are calculated by the example page. They are not official league tables published by the Finnish Football Association.

## Data source

All match and schedule data is loaded directly from the Finnish Football Association's Taso/TorneoPal service. An internet connection is required for the widgets to work.
